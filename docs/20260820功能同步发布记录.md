# 诵经助手功能同步发布记录

日期：2026-08-20

## 已完成

- 开示数据库升级至 schema v2，采用非破坏性迁移并为历史记录补齐稳定 ID 与排序。
- 新增版本化开示文件导入导出，支持批量预览、三种冲突策略、输入限制和逐文件事务隔离。
- 补齐开示收藏、完成、评论、排序、编辑删除、每日顺序/随机展示，以及 TTS、复制和跨平台分享降级。
- 同步十念法内置/自定义节奏、音色、预览、引用替换，以及念圣号开始、暂停、继续和停止状态。
- 修复 Windows 电子木鱼只播放第一声的问题：预加载并复用短音频、串行调度每次敲击，并防止最后一声被结束引磬提前截断。
- 修正拜忏钟声/TTS/计时顺序、资源释放和功课保存防重复。
- 将 `app_help_center` 从机器绝对路径改为发布依赖 `^0.2.6`。
- 将 `flutter_tts 4.2.0` 固定为项目内依赖，修复 Windows 播放完成回调从非平台线程访问 Flutter channel 导致的朗读崩溃。
- 修复多个 `FlutterTts` 实例覆盖完成事件处理器时的 Dart 回调兜底；Windows 原生插件通过平台线程创建的 message-only window 接收 MediaPlayer 完成消息，解决开示页朗读结束后播放按钮无法恢复的问题。
- 以本地 path 依赖接入 `my_flutter_app_tools 0.1.0`，并将最近同步页面的短消息统一迁移到 `AppToast`；旧页面通知机制暂时保留。
- Windows 善书听书取消单页限制，单双页均可从当前页连续朗读；跨双页组同步翻页，停止、手动导航和退出会终止旧会话。
- 修正 Windows CMake 默认安装前缀判断，Windows release 构建成功。
- 设置兼容下限为 Flutter 3.44.0 / Dart 3.12.2，并将 Flutter 3.47.1 stable / Dart 3.13.1 作为推荐且已验证的构建环境。

## 兼容与边界

- 保持生产入口既有 `app.db` 路径，仅执行 v1 → v2 增量升级。
- 未引入鸿蒙专用插件、ArkTS、桌面卡片、隐私确认页或启动失败页。
- Windows 不支持直接图片分享时复制图片到剪贴板；文本分享失败时复制文本。
